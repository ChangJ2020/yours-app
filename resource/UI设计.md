# Yours App (YA) 系统设计与需求规格说明书 (PRD v2.0)

## 1. 系统概述与核心原则

* **系统名称**：Yours App（简称 **YA**）
* **系统定位**：免登录、本地化、以“自然语言交互 + 配置驱动（Schema-Driven）”为核心的轻量级零代码应用生成与管理工作台。
* **核心原则**：
* **完全免鉴权**：系统自身及生成的子应用均无需登录/注册，开箱即用。
* **单机持久化**：应用元数据（Spec）与用户填报的数据均存储于浏览器本地持久化存储（IndexedDB / LocalStorage）。
* **单向生成，双向联动**：既支持“从对话从零生成”，也支持在 App 详情页“改动功能清单 $\rightarrow$ 联动更新 Spec $\rightarrow$ 重新构建应用”。

## 3. 核心机制：功能清单修改 $\rightarrow$ Spec 联动同步 $\rightarrow$ 重新构建闭环

这是详细页面的核心灵魂，将非技术人员的业务语言与底层的技术 Spec 建立双向绑定。

```
[用户在前端操作] 
修改/新增【功能清单】中的某一项 (如: "增加记录月度优秀员工")
         │
         ▼
[触发系统联动: Sync Spec]
系统将 (当前完整 Spec + 修改后的功能清单) 提交给后台/AI 快速推导
         │
         ▼
[Spec 动态热更新 (Diff & Patch)]
【详细 Spec】区域实时刷新，高亮展示新增的实体字段与新页面 (如增加 star_employee)
         │
         ▼
[用户点击: 重新构建 (Rebuild App)]
1. 执行数据架构版本升级 (v1.0.0 -> v1.1.0)
2. 执行本地存储无损升级检查 (保证原有工时填报数据不丢失)
3. 动态渲染引擎热重载，切回 [实际使用应用] 视图，新功能立即可用！

```

### 异常保护机制：

* **数据兼容保护**：如果用户删除了功能清单中的某项（对应 Spec 中删除了某个数据字段），在点击“重新构建”时弹出二次确认警示：*“该修改将导致‘工作内容描述’字段不再展示，原有数据仍保留在历史归档中，是否继续？”*

## 5. 前端工程模块与核心状态管理 (Implementation Architecture)

用于给 AI 直接生成系统代码时的核心工程模块分工：

| 模块目录 | 核心职责 |
| --- | --- |
| `src/views/HomeView.vue (或 .tsx)` | **首页视图**：集成顶部 Chat 生成窗口（1~4步）与底部 App 列表展示区。 |
| `src/views/AppDetailView.vue` | **App 详情工作台**：承载【实际使用】与【清单/Spec 联动编辑器】的 Tab 切换。 |
| `src/components/chat/ChatStudio.vue` | 对话交互组件：管理会话流、识别步骤状态标签 `<!-- STATE: ... -->` 并渲染对应进度条。 |
| `src/components/studio/FeatureEditor.vue` | **功能清单可视化修改器**：支持用户增删改功能卡片，向外 emit 变动事件。 |
| `src/components/studio/SpecPreview.vue` | **Spec 联动树形预览器**：展示当前 Spec 对应的字段表和页面配置，高亮改动部分。 |
| `src/components/engine/DynamicForm.vue` | 动态表单引擎：根据 Spec 的 fields 动态渲染 Input/Select/DatePicker 并校验必填。 |
| `src/components/engine/DynamicTable.vue` | 动态表格引擎：根据 Spec 渲染数据行，自带简易搜索、删除、CSV 导出。 |
| `src/services/storageService.ts` | **本地存储适配器**：通过 IndexedDB 维护两张核心表：<br>

<br>1. `apps_meta`（保存所有应用的 Spec）<br>

<br>2. `app_data_{appId}_{entityId}`（隔离保存每个应用的表单数据）。 |

# Yours App (YA)

> 基于自然语言交互的零代码应用即时生成平台 —— 说出你的业务诉求，四步对话得到一个**能立刻用**的轻量业务管理应用。

本工程是《构思.md》与《UI设计.md》(PRD v2.0) 的**可运行实现**：免登录、本地持久化、配置驱动（Spec-Driven），
支持从零生成应用，也支持在应用详情页「改功能清单 → 联动更新 Spec → 重新构建 → 数据无损迁移」的完整闭环。

---

## 一、快速开始

```bash
npm install --cache .npmcache --ignore-scripts   # 依赖已随仓库安装完成时可跳过
npm run dev                                      # 启动开发服务器（默认 http://localhost:5273）
```

打开浏览器访问提示的地址即可。首次打开会自动植入一个演示应用「员工工时记录助手」（含 14 条示例数据），
可直接进入体验填报、检索、导出、迭代与重建。

其它命令：

```bash
npm run build     # 生产构建，产物在 dist/（hash 路由，双击 index.html 也能用）
npm run preview   # 预览构建产物
npm test          # 引擎单元测试（30 项，Node 内置 test runner，零额外依赖）
npm run verify    # 端到端验证：真实无头 Chrome 走完整闭环 + 逐步截图（32 项检查）
```

> `npm run verify` 需要先启动 `npm run dev`；截图输出在 `verify-shots/`，同时生成 `report.json`。

## 三、两种生成模式

系统内置**双引擎**，运行时自动选择：

1. **内置规则引擎（默认，完全离线）**
   10 个业务领域模板（工时、库存、客户、报销、任务、资产、文档、员工、会议、质检）+ 关键词意图识别 +
   字段推导 + 跨领域功能补充。没有网络、没有 API Key 也能跑通完整四步闭环。

2. **真实大模型（可选）**
   点击右上角 ⚙️ 填入任意 **OpenAI 兼容接口**（DeepSeek / OpenAI / 通义 / 本地 Ollama 均可），
   即切换为流式对话生成；调用失败会自动回退内置引擎，并在界面标注原因。
   接口地址与密钥**只保存在浏览器本地**，不会上传到任何服务器。

## 五、关键设计决策

1. **不生成源码，生成 Spec**
   所有应用都由同一套「动态表单 + 动态表格 + 本地存储」引擎驱动，AI 只产出结构化 Spec，
   因此不存在生成不可控代码的问题，重建也只是替换 Spec 并迁移数据。

2. **字段只在编译期推导，功能清单只保留业务语言**
   功能清单里不缓存字段定义。否则用户在详情页删掉的字段，会在下一次重编译时被「长回来」——
   这是实现过程中真实踩到的坑，现已由「字段来源可追溯」的四条规则约束：
   已有 Spec 字段 → 领域模板核心字段（仅首次创建）→ 本轮新增功能的数据项 → 用户点名要的字段。

3. **意图与描述分离**
   字段推导只认「用户本轮说过的话」（intent），不认应用描述。描述里的「工作内容」等词
   曾把已删字段重新推导出来，分离后行为变得确定可测。

4. **删除即归档，不静默丢数据**
   删除字段重建时，旧值移入记录的 `_archived`，并在确认弹窗中明确告知影响范围，
   未勾选确认无法点击构建。

5. **唯一 key 保障**
   中文标签无法转拼音，字段 key 采用「前缀 + 标签哈希」，保证同一 Spec 内唯一
   （曾因两个中文字段拿到同一个 key，导致删除与迁移只生效一个）。

## 六、验证情况

- **单元测试**：`npm test` → 30/30 通过（意图识别、领域识别、功能增删改、Spec 契约、
  Diff/迁移、字段不复活、越界与脏数据兜底）。
- **端到端验证**：`npm run verify` → 32/32 通过。真实无头 Chrome 依次验证：
  冷启动播种 → 四步生成 → 动态表单校验与提交 → 表格检索/排序/导出 → 工作室双向联动 →
  重新构建与版本升级 → 删除已上线字段触发的归档保护与数据无损迁移 → AI 迭代 → 版本回滚 →
  主题切换 → 刷新后数据仍在 → 运行期零 JS 异常。
- `verify-shots/` 保留了每一步的截图（含弹窗与归档确认），可直接人工核对视觉效果。

## 七、已知边界

- 按 MVP 要求**不设登录与权限**，同一浏览器内的数据对所有人可见；多人协作需后续引入后端。
- 数据保存在浏览器本地，清理浏览器数据会同时清空应用与记录，请使用「导出配置」备份。
- 内置规则引擎对**发散型长句**的理解有限（这是规则引擎的固有边界），
  复杂需求建议在 ⚙️ 中配置真实模型；两者可随时切换，数据格式完全一致。
- 生成能力聚焦「单数据表 + 表单/表格页面」的轻量应用，暂不支持多表关联与复杂流程审批。
